About this editor

Menus and conversations come from canonical JSON definitions. State variants cover quests, ownership and activities. Generic casual conversations are shared across eligible NPCs. Conditions use the same JSON player state as the game. Repeated names and types share one entry. Definition details lists their world placements.

Edits stay in this browser until you choose Save to game. The local server writes sf/content/entities.json, dialogues.json, and texts.json. The game reloads content automatically. Export changes also saves a reviewable JSON file. Name changes and NPC/Object conversions apply to every placement in the selected entry.

Refresh the catalog with npm --prefix sf run build:editor. The normal game build refreshes it too.
